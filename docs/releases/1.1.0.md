# Codex Profiles 1.1.0

The first public release of Codex Profiles, a native macOS menu bar account switcher.

- Save, rename, favorite, search, and switch Codex accounts.
- Monitor separate 5-hour and weekly quota windows with reset times.
- Refresh account usage automatically and optionally show remaining quota in the menu bar.
- Hide email addresses for a cleaner display when sharing your screen.
- Check for app updates in Settings, with optional automatic downloading and installation.
- Verify update archives and feeds using Sparkle's Ed25519 signatures.
- Preserve live credentials when switching accounts and reject outdated refresh writes.

Requires macOS 14 or later. The GitHub release supports Apple Silicon and Intel Macs.

This project is independently developed and is not affiliated with OpenAI.
